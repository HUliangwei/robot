## 0. 流程总览

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────────┐   ┌──────────────┐
│ 数据采集   │ → │ 数据处理   │ → │ 模型训练   │ → │ 闭环推理/评估  │ → │ 部署/网页端    │
│ (遥操作/仿真)│   │ (检查/增强) │   │ (ACT等)   │   │ (官方2D/MuJoCo)│   │ (策略服务化)   │
└──────────┘   └──────────┘   └──────────┘   └──────────────┘   └──────────────┘
```

**核心概念**：LeRobot 负责 **数据 + 策略**；环境（`s' = f(s, a)`）由物理引擎提供（pymunk 或 MuJoCo）。
策略不依赖具体引擎——只要**观测空间 / 动作空间 / 任务几何一致**，同一份权重可直接切换环境。

## 3. 数据处理与理解

```bash
# 查看数据集结构 / 信息
python -m lerobot.scripts.lerobot_info --dataset.repo_id=lerobot/pusht
# 可视化数据（图像、动作、状态）
python -m lerobot.scripts.lerobot_dataset_viz --dataset.repo_id=lerobot/pusht
```

**数据组织**（LeRobotDataset v3.0 格式）：
```
pusht/
├── data/                 parquet（index / observation.state / action / ...）
├── videos/observation.image/   每 episode 一个 mp4（96×96 俯视图）
└── meta/                 info.json（features 定义）、stats.json（归一化统计量）、tasks.parquet
```

**关键理解**（对应 Notebook 01-03）：
- `observation.image` 是 uint8 图像，读入时除 255 → [0,1]；
- `observation.state` = 推块位置 [0,512]；`action` = 推块目标位置 [0,512]；
- `stats.json` 的 mean/std 会写进 checkpoint 的 pre/post processor（推理时必须配套使用）。

## 4. 模型训练

```bash
# ACT 训练（本项目实际运行过的命令；025000 checkpoint 产出成功）
$env:HF_HOME = "D:\Desktop\robot\datasets"
python -m lerobot.scripts.lerobot_train ^
    --dataset.repo_id=lerobot/pusht ^
    --policy.type=act ^
    --policy.push_to_hub=false ^
    --output_dir=workspace/pusht/outputs/train/act_pusht_real ^
    --steps=30000 --batch_size=64 --save_freq=5000 --save_checkpoint=true ^
    --env_eval_freq=0 --eval_steps=0 --wandb.enable=false
```

- checkpoint 保存在 `outputs/train/<job>/checkpoints/<step>/pretrained_model/`：
  `config.json + model.safetensors + policy_preprocessor.json + policy_postprocessor.json + 归一化统计量`。
- **经验**：ACT 在 PushT 上 loss 收敛快（l1 25k 步到 0.12），但**闭环成功率需要更久训练**。
  官方配方（~90%+ 成功率）：batch 8 + 60-80k 步（约 8-10h）。本项目 25k/batch64 与社区 80k/batch8 权重水平相当（max 覆盖率 0.6-0.9，未达 0.95 成功线）。
- 预训练权重可选：`aadarshram/act_pusht`、`Lemon-03/ACT_PushT_test`（社区）；`lerobot/act_pusht`（官方，gated）。

### 5.3 推理管线内部（网页端/服务化必须理解）

```python
# 1) 加载策略 + pre/post processor（注意：0.6.1 需分开加载）
from lerobot.policies.act.modeling_act import ACTPolicy
from lerobot.processor import PolicyProcessorPipeline
policy = ACTPolicy.from_pretrained(POLICY_PATH)
pre  = PolicyProcessorPipeline.from_pretrained(POLICY_PATH, config_filename="policy_preprocessor.json")
post = PolicyProcessorPipeline.from_pretrained(POLICY_PATH, config_filename="policy_postprocessor.json")

# 2) 每步闭环（观测转换与 lerobot 官方一致）
batch = {
    "observation.image":  pixels_uint8 / 255.0,   # (3,96,96) float
    "observation.state":  agent_pos,              # (2,) float
}
batch = pre(batch)                                  # MEAN_STD 归一化
action_norm = policy.select_action(batch)           # ACT: 每 100 步重新规划一次动作块
action = post({"action": action_norm})["action"]    # 反归一化回 [0,512]
obs, reward, done, trunc, info = env.step(action)
```

## 6. 网页端开发指引

思路：**策略推理与物理引擎分离**——网页前端只管展示，策略推理放在后端（Python 服务），
环境步进可选（演示用 MuJoCo，部署用真实机器人 API）。

```
浏览器 (HTML/JS 可视化)
    │  WS / REST  (obs 请求 → action 返回)
    ▼
Python 后端服务
    ├─ PolicyService（加载 checkpoint + pre/post，GPU 推理，~5-15ms/步）
    ├─ EnvDriver（MuJoCo 环境 / 官方 2D / 真实机器人适配器）
    └─ 回放/录制（逐帧图像 + 覆盖率 + 奖励 → 前端曲线）
```

最小化服务示例（FastAPI）：

```python
# server.py（骨架）
from fastapi import FastAPI
import numpy as np
from run_pusht_rollout import make_policy, obs_to_batch

app = FastAPI()
policy, pre, post = make_policy("aadarshram/act_pusht")

@app.post("/action")
def get_action(pixels: list, agent_pos: list):   # pixels: 96*96*3 uint8
    batch = pre(obs_to_batch({"pixels": np.array(pixels, np.uint8),
                              "agent_pos": np.array(agent_pos, np.float32)}))
    a = post({"action": policy.select_action(batch)})["action"]
    return {"action": a.squeeze(0).tolist()}
```

- 前端可直接使用 `docs/inference_report.html` 的布局与 GIF 作为展示参考；
- 实时可视化：每步把环境渲染帧（MuJoCo `env.render()` 512×512）编码为 JPEG/WebP 推给前端。

## 7. 常见问题（本项目踩过的坑）

| 问题 | 解决 |
|---|---|
| gym_pusht 报 `add_collision_handler` 不存在 | pymunk 7 移除了该 API，`pip install pymunk==6.8.0` |
| `lerobot-eval` 传 hub repo id 报路径错误 | Windows 上会被转成 WindowsPath，改用本地目录 |
| `ACTPolicy.from_pretrained` 后没有 preprocessor | 0.6.1 需用 `PolicyProcessorPipeline.from_pretrained` 单独加载 |
| MuJoCo 渲染全黑 | 渲染前必须 `mj_forward`；相机距离 < `zfar×extent` |
| MuJoCo 颜色发白 | 关闭高光：`<material specular="0"/>`（放 `<asset>` 而非 default） |
| T 形覆盖率计算崩溃 | 用 MultiPolygon（两个矩形），不要用 8 顶点单 Polygon |
| 官方 `lerobot/diffusion_pusht` 无法加载 | 旧格式 checkpoint，0.6.1 迁移脚本有 bug，暂用 ACT |
