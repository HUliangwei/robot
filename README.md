# Robot Learning Workbench (RLW)

Robot Learning Workbench (RLW) 是面向具身智能（Embodied AI）的实验控制平台。

目标：
将机器人学习实验从零散脚本转变为可追踪、可复现、可扩展的 Experiment Control Plane。

核心概念：

- Experiment（实验）
- Trial（实验配置）
- Run（运行实例）
- Job（执行任务）
- ExecutionAttempt（执行尝试）
- Artifact（实验产物）
- Provider（能力适配层）
- Executor（执行器）

Golden Path:

Recipe
 ↓
Prepare
 ↓
Execute
 ↓
Evaluate
 ↓
Reconcile
